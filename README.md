## Destino turístico asignado
**Montañita – Santa Elena, Ecuador**

Enfoque: **playa, surf, gastronomía, hospedaje y entretenimiento**.

## Descripción del proyecto
Montañita Wave Tours es una agencia turística ficticia desarrollada como examen práctico.
El sitio presenta información turística organizada sobre Montañita, sus atractivos,
servicios y paquetes referenciales, información institucional y un formulario HTML5
de contacto/reserva.

## Tecnologías utilizadas
- HTML5 semántico
- CSS3
- Flexbox
- CSS Grid
- Box Model
- Pseudoclases `:hover` y `:focus`
- Media Queries
- Diseño responsive
- Git y GitHub
- GitHub Pages

## Páginas del sitio
1. `index.html` — Inicio
2. `destinos.html` — 6 lugares/experiencias turísticas de Montañita
3. `servicios.html` — 6 servicios o paquetes turísticos
4. `nosotros.html` — Historia, misión, visión, valores e información del destino
5. `contacto.html` — Formulario HTML5 de contacto / reserva
